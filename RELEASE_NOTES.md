# Mojo Carrot Pet 1.0.1

## Changes

- Fixed transparent areas around 卜卜 blocking mouse wheel scrolling and clicks in underlying apps.
- Pointer interaction now follows visible pet pixels; the right-click menu remains interactive while open.

## Download Safety

Download installers only from this GitHub Release.

Do not install copies from cloud drives, group chats, third-party websites, or reuploaded installer links. If the installer is not from this repository's GitHub Release, do not run it.

Verify the downloaded file with `SHA256SUMS.txt` before installing.

## Assets

- macOS Apple Silicon: `Mojo.Carrot.Pet-1.0.1-arm64.dmg`
- Windows x64: `Mojo.Carrot.Pet.Setup.1.0.1.exe`
- Checksums: `SHA256SUMS.txt`
